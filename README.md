# Vending Doc

Official site for **Vending Doc** — Ireland’s first network of machines that mix premium protein shakes fresh, on demand, inside gyms, leisure centres, and hotels.

**Fresh Protein. On Demand.**

## Stack

React 19, TypeScript, Vite, TanStack Start, Tailwind CSS.

## Local

```bash
npm install
npm run dev
```

The app serves on port 8080.

```bash
npm run typecheck
npm run build
```

## Request form

Venue enquiries submit through the on-site form and are stored in the app database.

## Brand

Navy, silver, and charcoal. Logo lives at `public/logo.jpg`.
